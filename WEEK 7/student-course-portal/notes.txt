angular.json
Contains Angular project configuration.

tsconfig.json
TypeScript compiler configuration.

tsconfig.app.json
TypeScript settings for the application.

package.json
Lists project dependencies and scripts.

src/main.ts
Entry point of the Angular application.

app.config.ts
Contains application configuration (Angular 20 standalone).

app.component.ts
Root component of the application.

index.html
Main HTML page loaded by the browser.
